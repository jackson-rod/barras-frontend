# Performance

Performance is the most important quality of Barras. These are the frontend budgets.

| Budget | Target |
| --- | --- |
| Cold start to an interactive Home, mid-range Android | ≤ 2.0 s |
| Screen transition to first frame | ≤ 100 ms |
| Lists and chart pan or zoom | 60 fps |
| Typecheck | ≤ 5 s |
| Lint | ≤ 2 s |
| Unit tests | ≤ 30 s |
